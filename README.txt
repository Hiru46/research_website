AURALEARN ACADEMIC WEBSITE SUBMISSION PACKAGE

Open index.html in a browser. Keep the documents and presentations folders beside index.html so all links continue to work.

The package contains local copies of the available project evidence. Files ending in .txt inside documents and presentations are submission slots because the approved originals were not available in the repository. Replace those files with the official Project Charter, checklist documents, final documents, and presentation files before uploading.

This package is independent from the main project workspace. It contains no links that depend on the original repository paths.
